## Descripción del Trabajo
Este proyecto académico consistió en el diseño, migración, transformación e integración de la información transaccional y territorial de la empresa **Gaseosas Poderosas** hacia una base de datos relacional centralizada en PostgreSQL.

El trabajo abarca desde el modelado relacional en Tercera Forma Normal (3FN) basado en la codificación del DANE, hasta la construcción de un pipeline ETL automatizado en Python para el perfilamiento y saneamiento de 10.000 registros de ventas. Asimismo, se desarrollaron consultas analíticas en SQL y tableros visuales para extraer hallazgos clave de negocio e informar decisiones estratégicas ante la Junta Directiva.
